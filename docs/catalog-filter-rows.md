# 商品列表上方的多行条件筛选

条件筛选原先放在左侧分类栏，项目和地区多时需要在窄栏中滚动。首页与商品页现在将筛选放在商品列表上方，每个维度独占一行，选项横向排列并自动换行。分类栏保留分类导航，手机分类抽屉保留焦点管理。

每行默认显示六个选项，可展开、搜索和继续加载；收起后已选条件仍可见、可清除。没有嵌套滚动框，手机采用同一布局并保留至少44像素的触控高度。上级条件变化仍清除下级，分页、网址中的稳定编号、商品重命名、地区新增和错误提示沿用原契约。
