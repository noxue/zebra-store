## 身份与职责

- 商品维持原本的本地ID、分类和SKU。接码按项目/国家形成商品，IP按地区/类型/线路形成商品；周期继续属于该商品下真实存在的SKU。
- 筛选维度V1为`family/project/country/city/ip_type/line`，每商品每维度至多一个值。静态是商品族，原生/广播是IP类型；营销用途继续使用信息标签，不复制SKU、价格或库存池。
- `value_id`是来源稳定标识的有界、不归一化字符串；`label`是可变化的三语显示值。名称、位置、售价均不能生成身份。缺少权威ID时省略该维度，不从名称猜地理或线路。
- 筛选资料没有购买、调价、库存或续费授权。列表数量表示匹配商品数，不是代理或号码库存；新购缺货但可续费的卡不应因筛选被错误描述成有新IP库存。
- 最终选择落到实际本地SKU ID；订单、上游映射、价格、交付及退款继续走原流程。已售卡和原订单快照不因筛选更新改变。

## 存储和同步契约（持久化已实现，发布同步待接线）

不改生成的products实体；在`entity/extra`增加商品筛选文档和规范化值行。文档保存正整数版本及schema版本，值行以商品/维度唯一，保存稳定值和显示名称，索引支持维度/值/商品查询。值行另保存原标识的精确字节，避免文本列的大小写不敏感排序规则改变身份；分组、精确匹配和排序使用该字节值，显示名称不能当身份。此表尚未在任何生产版本发布，最终版本由现网原无此表的版本通过entity-first创建。表结构由现有entity-first机制建立，不在运行代码添加方言建表SQL。

HTTP的revision/expected_revision为精确十进制字符串，内部和PG保持有界整数，避免JavaScript大整数失真；拒绝数字、符号、补零、空白及越界版本。首次文档版本0；每次替换要求`expected_revision`与当前版本相同。锁定同一商品，在同一事务内验证存在/未删除、检查版本、整体替换及递增版本；任何无效值整批拒绝。清空仅删除值行，保留递增文档版本，防止旧请求按版本0重放；即便此前为空/尚无文档，显式清空也推进版本，拦截尚未到达的旧初始写入。非空同值且版本一致的更新可以无写返回。无需历史引用的筛选值行可硬删后重建，不让软删占用唯一键（ORD-11）；购买SKU及库存保护维持原规则。

来源发布器只更新自己已核验归属的商品。改名更新label，新增地区增加值，ID冲突停止相关发布；不覆盖人工商品名和售价。对原商品GET/版本/归属确认后持久记录一次写意图，写超时先读原目标核对，不盲目重写。读回筛选值、三价及SKU绑定后才允许发布。人工修改导致版本不符时进入待核对，不强制覆盖。

核心Zebra v1不增加未经协商的字段。通过Store可选的管理HTTP接口设置筛选资料，使用公开能力发现明确V1支持；旧Store或旧上游没有此功能时保持原协议。要求结构化浏览的发布任务遇到能力缺失须明确暂停，不能称已完成筛选。

## HTTP与权限（管理及公开端已在本地实现，现网尚不可调用）

| 路由 | 契约 |
| --- | --- |
| GET `/api/v1/public/catalog-facets` | 返回实际支持版本/维度，不返回隐藏商品或供货账号信息 |
| GET `/api/v1/public/catalog-facet-values` | 维度、当前筛选、分类/关键词、选项搜索、分页；可按value_id精确解析已选项；只统计当前租户可见商品 |
| GET/PUT `/api/v1/admin/products/:id/catalog-facets` | 当前文档版本/整体替换；PUT包含schema_version、expected_revision和facets，拒绝未知字段 |
| GET `/api/v1/public/products` | 新增可选facet_family/project/country/city/ip_type/line，缺省保持原返回/排序/分页及价格行为 |

管理路由已加入权限目录及operations内置角色；无认证401、无操作员权限403、成功写入/读回已由真实路由验证。普通用户无权写入。错误分别映射非法标识/名称、重复维度、版本冲突、商品不可用；三语提示不输出供应商原文或内部错误。表单、请求及标签长度有界。

筛选在服务端分页之前执行，同维度单选、跨维度求交。候选选项忽略自身维度选择但应用其他条件，按真实共现组合提供，不能虚构笛卡尔积。分类停用/父分类停用/软删除/分站隐藏均同时作用于列表、选项和计数，跨页数据不在浏览器收齐后筛。使用查询构建器和绑定参数，不拼接用户SQL，不为业务查询分支三种数据库方言。列表与选项复用同一公开可见性筛选器；停用/不存在的分站在分页之前形成空范围，读取分站数据失败则返回错误，不能冒充空列表。

选项按精确字节标识排序，分页大小沿用1–200的公开分页规则；拒绝超出数据库有符号offset范围的页码。`option_search`最长160字符且无控制字符，三语标签支持不区分大小写的字面搜索，`%/_`不作通配符；普通`search`仍搜索商品。可同时提供`value_id`精确取回URL选中项，不必收齐前面的页。每个ID以可见范围内最大行序号对应的标签显示（以写入序号确定代表，不以提交时间猜顺序）；先分组、后搜索标签，改名不会丢掉同ID其他商品的计数。候选选项、总数和该页计数使用一个只读重复读取事务；SQLite仍使用其原生事务读取快照。未知但格式合法的ID返回空范围，非法ID/页码/选项搜索分别返回明确三语错误。未知schema的文档不贡献公开筛选值，损坏的选项身份/标签明确失败。

`CatalogFacetFilters`及能力/选项类型已接入前台`api`层；这不表示视图已经渲染了筛选控件。

## 客户界面（待实现）

先选商品族，再按当前真实选项选项目、国家、城市、类型或线路。选项支持服务端搜索和分页加载，显示名称而不是内部ID；分享URL只保存稳定ID，显示名由接口查回。父条件变化清理失效子条件，清除筛选恢复普通商品列表。

移动筛选抽屉提供当前选择、清除和确认，键盘/屏幕阅读语义完整，不横向溢出。请求乱序不能覆盖新条件；选项/商品加载失败有明确重试提示，不能显示为权威无货。无筛选资料的旧商品保留现有体验。
