# dujiao-next 协议

对方是 [dujiao-next（独角数卡 Next）](https://github.com/dujiao-next/dujiao-next) 或者兼容它的站点时使用。
斑马小铺和 dujiao-next 的接口完全一致，两个方向都可以对接。

这一页假设对方站点已经在运行；dujiao-next 的安装方法请看它的 [官方仓库](https://github.com/dujiao-next/dujiao-next)。

## 方向一：本站从 dujiao-next 进货

### 1. 在对方站点准备账号

1. 打开对方 dujiao-next 前台，注册一个账号；
2. 个人中心 → **API** → 申请 API 凭证；
3. 请对方站长在他的后台审核通过；
4. 回到个人中心复制 **API Key** 和 **API Secret**；
5. 在对方站点给这个账号充值余额（采购时从这里扣款）。

### 2. 在本站添加连接

本站后台 → **对接管理 → 连接管理** → **新建连接**：

| 字段 | 填写 |
|---|---|
| 对接协议 | **dujiao-next** |
| 站点地址 | 对方网址，例如 `https://dujiao.example.com` |
| API Key / API Secret | 上一步复制的 |
| 回调地址 | `https://你的域名/api/v1/upstream/callback`（对方发货后通知本站） |
| 汇率 | 同币种填 1 |
| 加价百分比 | 例如 20 |

点 **测试连接**，成功后保存。

![新建 dujiao-next 连接](/screenshots/integration/dujiao-connection.png)

### 3. 导入商品并上架

**对接管理 → 商品映射 → 导入商品**，选择连接、勾选商品、选择本站分类、导入，然后在商品列表里上架。

### 4. 发货是异步的

dujiao-next 收单后**稍后**才发货。本站会通过两种方式拿到结果：

- 对方发货后调用本站的回调地址（最快）；
- 本站定时查询采购单状态（兜底，回调不通时也能拿到）。

所以买家付款后，订单会先显示“发货中”，一般几十秒内变为“已交付”。

::: tip 回调地址访问不到时
dujiao-next 不会回调内网地址。如果本站在内网，可以不填回调地址，靠定时查询也能完成，只是慢一点。
:::

## 方向二：dujiao-next 从本站进货

1. 对方在**本站前台**注册账号 → 个人中心 → **API 对接** → 申请；
2. 你在本站后台 **对接管理 → API 凭证** 点 **通过**；
3. 对方在本站个人中心复制 API Key 和 Secret，并在本站**充值余额**；
4. 对方在**他的** dujiao-next 后台 **对接管理 → 连接管理** 新建连接：
   协议 `dujiao-next`，站点地址填**本站网址**，填 Key 和 Secret，回调地址填他自己站点的回调地址；
5. 对方导入本站商品并上架。

之后对方的买家下单时，对方站点调用本站的 `/api/v1/upstream/*` 接口，从他在本站的余额扣款；
本站发货后会签名回调他的站点。

## 常见问题

**测试连接失败**：检查地址是否带了 `https://`、Key 和 Secret 是否复制完整、凭证是否已审核并启用。

**对方返回余额不足（402）**：去对方站点充值，然后在本站 **采购单管理** 点 **重试**。
