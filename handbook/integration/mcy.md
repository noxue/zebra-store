# 萌次元 mcy-shop

萌次元商城（[mcy-shop](https://github.com/lizhipay/mcy-shop)）通过 **OpenApi 插件** 对外供货。
这个协议也被异次元发卡的 **“萌次元(V4.0)”** 店铺类型使用。两个方向都支持。
这一页假设对方站点已经安装好，安装方法请看官方仓库。

## 方向一：本站从萌次元商城进货

1. 在对方萌次元商城注册账号，确认对方安装了 OpenApi 插件；
2. 在个人中心找到 **API-ID**（就是用户 ID）和 **API 密钥**；在对方站点充值余额；
3. 本站后台 → **对接管理 → 连接管理** → **新建连接**：

| 字段 | 填写 |
|---|---|
| 对接协议 | **萌次元商城** |
| 站点地址 | 对方网址 |
| API-ID（用户 ID） | 对方个人中心的 API-ID |
| API 密钥 | 对方个人中心的密钥 |
| 供货站结算货币 | 一般是 `CNY` |
| 汇率、加价百分比 | |

4. **测试连接** → 保存 → **商品映射** 导入商品 → 上架。

特点：全量同步、按 SKU 同步价格和库存、余额下单时同步拿到卡密。
对方没有查单和回调接口，结果不明的采购单会进入 **待人工核对**，绝不会重复下单。

## 方向二：异次元（萌次元类型）或 OpenApi 客户端从本站进货

1. 对方在**本站**注册 → 申请 API 凭证 → 本站站长审核 → 在 **API 对接 → 异次元 / 萌次元 对接** 生成对接密钥 → 在本站充值；
2. 对方在异次元后台 **店铺共享 → 添加店铺**：

| 字段 | 填写 |
|---|---|
| 类型 | **萌次元(V4.0)** |
| 店铺地址 | 本站网址 |
| API-ID | 本站给的商户 ID |
| API 密钥 | 本站给的对接密钥 |

3. 连接 → 拉取商品 → 导入 → 上架。

::: tip 同一个站点想用两种类型各连一次
异次元不允许同一个店铺地址保存两次。如果已经用“异次元”类型添加过本站，
再用“萌次元(V4.0)”类型添加时，把地址换一种写法（例如末尾加 `/`）。
:::

限制与 [异次元方向二](./acg-faka#_3-限制) 相同：只提供自动发货商品，重复的订单号返回原订单，同样建议设置 IP 白名单。
