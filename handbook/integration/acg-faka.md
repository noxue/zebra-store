# 异次元发卡 acg-faka

对方站点运行 [异次元发卡（acg-faka）](https://github.com/lizhipay/acg-faka) 时使用，两个方向都支持。
这一页假设对方站点已经安装好；安装方法请看 acg-faka 的 [官方仓库](https://github.com/lizhipay/acg-faka)。

异次元的对接功能叫 **“店铺共享”**：进货方在后台添加一个“共享店铺”，填对方的地址、商户 ID 和密钥。

## 方向一：本站从异次元进货

### 1. 在异次元站点准备账号

1. 在对方异次元前台**注册会员**；注册后系统会自动生成**对接密钥**（app_key）；
2. 在会员中心找到你的 **用户 ID**（商户 ID）和 **对接密钥**；
3. 在对方站点充值**余额**（采购时强制用余额支付）；
4. 请对方站长确认要卖给你的商品在他后台开启了 **“开放对接”**，否则看不到这些商品。

### 2. 在本站添加连接

本站后台 → **对接管理 → 连接管理** → **新建连接**：

| 字段 | 填写 |
|---|---|
| 对接协议 | **异次元发卡** |
| 站点地址 | 对方网址，例如 `https://acg.example.com` |
| 商户 ID（app_id） | 你在对方的用户 ID |
| 对接密钥（app_key） | 你在对方的对接密钥 |
| 供货站结算货币 | 对方用什么货币就填什么，一般是 `CNY` |
| 汇率、加价百分比 | 同币种汇率填 1；加价例如 20 |

点 **测试连接**：成功时显示对方店名和你的余额。

![新建异次元连接](/screenshots/integration/acg-connection.png)

### 3. 导入商品

**商品映射 → 导入商品**：异次元商品里的“种类”（例如月卡 / 季卡）和“规格”会自动展开成本站的多个 SKU，
价格按你在对方的**拿货价**计算。导入后默认下架，检查后上架。

如果对方商品要求填写信息（例如游戏账号），这些“控件”会变成本站的下单表单，
对方设置了格式要求（正则）时，本站结算时就会校验，避免买家付款后才被对方拒绝。

### 4. 下单与交付

异次元是**同步交付**：本站下单的同时就拿到卡密，买家付款后几秒内就能看到。

需要注意：

- 异次元没有“查单推送”，也没有锁价，价格和库存靠定时同步（默认 5 分钟）；
- **余额不足**时采购单进入“已拒绝”，**不会**自动重试，充值后在采购单上点 **重试**；
- 请求超时等情况下，本站无法确定对方是否成交，采购单进入 **待人工核对**，**绝不会**自动重复下单。
  请到对方后台核对订单后再决定重试或取消，见 [采购单与故障处理](./procurement)；
- 对方的**人工发货**商品：对方返回的是提示文字而不是卡密，采购单会停在“已接受”，需要你在对方发货后手动处理。

## 方向二：异次元从本站进货

### 1. 对方在本站准备账号（对方操作）

1. 在**本站前台**注册账号 → 个人中心 → **API 对接** → 申请 API 凭证；
2. 本站站长在后台 **对接管理 → API 凭证** 点 **通过**；
3. 回到 **API 对接** 页面的 **异次元 / 萌次元 对接** 区域，点 **生成对接密钥**，记下：**站点地址**、**商户 ID**、**对接密钥**；
4. 在本站**充值余额**（对方每次进货从这里扣款）。

![本站生成兼容密钥](/screenshots/storefront/me-api-compat.png)

### 2. 在异次元后台添加共享店铺（对方操作）

异次元后台 → **店铺共享** → **添加店铺**：

| 字段 | 填写 |
|---|---|
| 类型 | **异次元(V3.1.2+)** |
| 店铺地址 | 本站网址，例如 `https://shop.example.com` |
| 商户 ID | 上一步的商户 ID |
| 密钥 | 上一步的对接密钥 |

保存后点 **连接**，能看到本站店名和余额就成功了。然后拉取商品、选择要卖的商品导入、设置加价、上架。

![异次元后台添加共享店铺](/screenshots/integration/acg-shared-store.png)

### 3. 限制

- 只提供本站的**自动发货**商品（异次元会把返回的内容直接当作最终卡密，人工发货商品无法送达）；
- 本站商品的多个规格在异次元里显示为多个“种类”；
- 价格是按对方账号计算的拿货价（会员等级、批发价都会生效）；
- 同一个请求号重复下单，本站返回原来的订单，不会重复扣款；
- 价格为 0 的商品不会被卖出（防止配置错误导致白送）。

::: warning 安全
异次元协议没有时间戳和防重放机制，异次元的客户端还会在请求里明文带上密钥。请务必：
本站使用 HTTPS；在 **API 对接** 页设置 **IP 白名单**（填对方服务器 IP）；怀疑泄露时立即 **重置密钥**。
:::

## 常见问题

**对方提示“商户ID不存在”**：商户 ID 填错；或者凭证被停用、用户被禁用、兼容对接开关被关闭、IP 不在白名单里（出于安全，这些情况都返回同一个提示）。

**对方提示“密钥错误”**：密钥填错，或者已经重置过。

**对方提示“该商品未开放对接”**：这是人工发货商品，或者商品已下架、分类已停用。

**本站“API 对接”页显示本站未开启**：站长在配置里关闭了 `integration.acg_faka_compat`。
