# 结算与提现

## 利润的几种状态

| 状态 | 意思 |
|---|---|
| 待确认 | 订单刚付款，还在结算确认期内（默认 7 天），不能提现 |
| 可用 | 确认期结束，可以提现 |
| 锁定 | 已经申请提现，等站长处理 |
| 已提现 | 站长已打款 |
| 已取消 | 被撤销、不再计入余额的记录 |

结算确认期由配置 `reseller.settlement_confirm_days` 决定（0–3650 天）。建议**不短于退款期限**，
否则利润被提走之后买家才退款，分销余额会变成负数。

## 分销商：申请提现

分销控制台 → **财务** 查看可用余额 → **提现**：

1. 填写金额（不能超过可用余额）、货币、提现渠道、收款账号；
2. 提交后这部分金额变为 **锁定**；
3. 等站长处理，在提现记录里看结果。

![分销商提现](/screenshots/reseller/withdraw.png)

不能提现的情况：

- 余额为负（之前的退款扣回超过了可用利润），要先由新的利润补上；
- 站长把你的结算状态设为 **冻结**；
- 分销商被禁用。

同时提交多笔提现也不会超出可用余额。

## 站长：打款或驳回

后台 **分销商管理 → 分销提现**：

- 按对方填写的渠道和账号**线下转账**，然后点 **打款**：锁定的金额变为已提现；
- 或者点 **驳回** 并写原因：锁定的金额回到可用。

如果一笔提现只用掉了某条利润的一部分，系统会自动把这条利润拆成两条，剩下的部分继续可用。

## 对账

- 分销商看 **流水**：每一笔利润、扣回、提现锁定、提现支付；
- 站长看 **分销流水**、**分销余额** 和 **分销概览** 里的财务表：成交额、利润、退款扣回、已提现、当前可用 / 锁定 / 负余额 / 待提现。
