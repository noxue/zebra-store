# 加价与利润计算

## 几个价格

| 名称 | 意思 |
|---|---|
| **基础价（代理价）** | 管理员为本分站设置的商品或规格代理价；未设置时使用统一 SKU 代理价，再未设置时使用主站 SKU 售价 |
| **成本价** | 站长在商品里填的成本（可以不填） |
| **分站售价** | 买家在分站看到并支付的单价 |
| **利润** | 分站售价 − 本分站有效代理价 |

## 四种定价方式

分销商可以对**商品**或**单个规格**设置：

| 方式 | 分站售价 | 例子（基础价 10.00） |
|---|---|---|
| 继承 | 使用上一级的规则 | — |
| 按百分比加价 | 基础价 ×（1 + 百分比），保留两位小数 | 加价 15% → 11.50 |
| 固定加价 | 基础价 + 固定金额 | 加 2.00 → 12.00 |
| 固定售价 | 直接指定 | 13.00 |

**规则的优先级**：规格的规则 → 商品的规则 → 分销商的默认加价（站长审核时设置）→ 主站对应规格的售价。
“继承”表示跳过这一级，看下一级。

分站没有设置商品售价且默认加价为 0 时，买家看到的价格与主站该规格的售价相同，分站可以直接销售。利润仍按“分站售价 − 有效代理价”计算；如果主站售价低于有效代理价，为避免亏损，默认售价取有效代理价。自动继承主站售价不受“最高加价”限制，分销商手动设置的价格和默认加价仍受限制。

管理员可在 **分销商品配置** 中输入分销商 ID 和商品 ID，为该分站的商品或某个 SKU 单独设置代理价；SKU 代理价优先于商品代理价。留空会沿用统一代理价。分销商能调整自己的售价规则，但不能修改或清除管理员设置的代理价。

## 限制

一个规则必须同时满足下面几条才能保存（在控制台点 **预览** 可以先检查）：

1. 分站售价大于 0；
2. 分站售价**不低于有效代理价**；它可以低于主站售价；
3. 分站售价**不低于成本价**（如果站长填了成本价）；
4. 隐含的加价比例**不超过最高加价**（站长审核时设置）。

统一代理价和分站代理价都必须为正且不低于对应 SKU 的成本价。修改成本后若旧代理价失效，该 SKU 会暂时从分站隐藏，下单也会被拒绝，直到管理员修正价格。

例：基础价 10.00、成本价 9.00、最高加价 50%：

| 规则 | 分站售价 | 结果 |
|---|---|---|
| 加价 15% | 11.50 | 可以 |
| 固定售价 15.00 | 15.00（加价 50%） | 可以（刚好等于上限） |
| 固定售价 16.00 | 16.00（加价 60%） | 不行：超过最高加价 |
| 固定售价 9.50 | 9.50 | 不行：低于基础价 |

如果站长之后调高了基础价或成本价，导致已保存的规则不再满足条件，这个规格会在分站**暂时隐藏**，
直到分销商修改规则。

## 完整例子

设置：基础价 **10.00**，分销商 sakura 对该商品设置 **加价 15%**，结算确认期 **7 天**。

**第 1 天**：买家在 `sakura.example.com` 买了 **3 件**。

- 分站售价 = 10.00 × 1.15 = **11.50**
- 买家实付 = 11.50 × 3 = **34.50**
- 主站收入中属于站长的基础部分 = 10.00 × 3 = 30.00
- 分销商利润 = 34.50 − 30.00 = **4.50**，记为“订单利润”，状态 **待确认**，可用时间为第 8 天

**第 3 天**：买家申请售后，站长给这单**退款 11.50**（一件的钱）。

- 退款比例 = 11.50 ÷ 34.50 = 1/3
- 扣回利润 = 4.50 × 1/3 = **1.50**，记为“退款扣回”，状态同样是待确认
- 这一单剩余利润 = 4.50 − 1.50 = **3.00**

**第 8 天**：确认期结束，结算任务把这两条流水变成 **可用**，分销商可用余额 = **3.00**。

**第 9 天**：分销商申请提现 3.00 → 余额被锁定 → 站长线下转账后点 **打款** → 流水变为“已提现”。

::: tip 退款扣回的规则
- 扣回比例总是用这一单的**全部实付金额**做分母；
- 同一单累计扣回的利润不会超过这单的利润；
- 最后一笔把订单全部退完的退款，正好扣掉剩下的全部利润（不会因为四舍五入多扣或少扣）。
:::

## 分销商自己在自己的分站买东西

不产生利润（防止自买自卖套利）。

## 分站上没有的优惠

分站结算页**不显示优惠券**，所以利润计算不受优惠券影响。
