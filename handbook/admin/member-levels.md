# 会员等级

## 用途

按用户的累计充值或累计消费自动升级，不同等级享受不同折扣，鼓励老客户多买。

## 入口

**用户管理 → 会员等级**。

![会员等级](/screenshots/admin/member-levels.png)

## 字段说明

| 字段 | 说明 |
|---|---|
| 名称 | 三语，例如“青铜 / 白银 / 黄金” |
| 别名 | 英文标识 |
| 图标 | Emoji 或图片 |
| 折扣率 | 例如 `95` 表示 95 折，`100` 表示不打折 |
| 充值门槛 | 累计充值达到多少自动升到这一级 |
| 消费门槛 | 累计消费达到多少自动升到这一级 |
| 默认等级 | 新注册用户自动获得的等级，只能有一个 |
| 排序、启用 | |

满足任一门槛即可升级；只会往上升，不会自动降级。

**回填默认等级**：给所有还没有等级的老用户设置默认等级（必须先设置一个默认等级）。

## 手动调整

在 **用户详情** 里可以直接给某个用户指定等级。

## 常见问题

**折扣没生效**：确认用户已登录；商品如果单独设置了会员价，以会员价为准。
