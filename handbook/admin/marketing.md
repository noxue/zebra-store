# 优惠券、活动价、批发价、礼品卡

## 入口

**营销管理 → 优惠券 / 活动价 / 批发价 / 礼品卡**。

## 优惠券

![优惠券](/screenshots/admin/coupons.png)

| 字段 | 说明 |
|---|---|
| 券码 | 买家在结算页输入的代码 |
| 类型、面值 | 百分比（例如 10 表示减 10%）或固定金额 |
| 适用商品 | 可以多选，支持搜索、全选；不选表示全部商品 |
| 最低金额 | 满多少才能用 |
| 最大优惠 | 百分比券的优惠上限 |
| 总次数 / 每人次数 | 0 表示不限 |
| 不与批发价同享 | 勾选后，达到批发价的订单不能用这张券 |
| 按件优惠 | 仅固定金额券：每件商品都减这个金额 |
| 可用身份 / 会员等级 | |
| 开始 / 结束时间、启用 | |

## 活动价

给**单个商品**设置限时优惠：活动名、商品、类型（百分比 / 固定金额）、面值、最低金额、开始和结束时间、启用。

![活动价](/screenshots/admin/promotions.png)

## 批发价

列表显示所有商品及其批发阶梯。点 **配置**：

1. 添加阶梯：规格（多规格商品需要选择）、起购数量、单价；
2. 保存。**清空批发价** 删除该商品所有阶梯。

例如“≥5 件 8.00、≥10 件 7.50”：买 5–9 件每件 8.00，10 件以上每件 7.50。

![批发价配置](/screenshots/admin/wholesale.png)

## 礼品卡

![礼品卡](/screenshots/admin/gift-cards.png)

- **生成**：名称、数量、面额、过期时间 → 系统生成对应数量的卡号；
- **编辑**：名称、状态（有效 / 停用）、过期时间；
- **批量**：勾选后批量启用 / 停用、导出（txt / csv），用来发给客户或者上架到别的平台；
- **筛选**：卡号、状态（有效 / 已过期 / 已兑换 / 已停用）、创建时间。

买家在前台兑换后，面额加到钱包余额，列表显示兑换人和兑换时间。

## 常见问题

**优惠券提示已用完**：检查总次数和每人次数；取消或过期的订单会退回次数。
