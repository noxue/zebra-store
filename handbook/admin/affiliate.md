# 推广返利

## 用途

让用户帮你推广：用户分享推广链接，别人通过链接下单后，推广人获得订单金额一定比例的佣金。

## 入口

**推广返利 → 返利设置 / 返利用户 / 佣金记录 / 提现审核**。佣金记录和提现审核需要先完成 [合规确认](./#合规确认)。

## 返利设置

![返利设置](/screenshots/admin/affiliate-settings.png)

| 字段 | 说明 |
|---|---|
| 启用 | 关闭后前台不显示推广入口 |
| 返利比例 | 例如 `10` 表示订单金额的 10% |
| 确认天数 | 佣金产生后多少天变成可提现，建议不少于退款期限 |
| 最低提现金额 | |
| 提现渠道 | 一行一个，例如“支付宝”“USDT-TRC20”，买家提现时从中选择 |

商品编辑里可以关闭单个商品的“参与推广返利”。

## 返利用户

所有开通了推广的用户：推广码、点击数、有效订单、转化率、待确认 / 可提现 / 已提现佣金、状态。
可以单个或批量**停用**，停用后该推广码不再产生新佣金。

## 佣金记录

每一笔佣金：推广人、订单号、订单金额、比例、佣金、状态（待确认 / 可提现 / 已驳回 / 已提现）、确认时间。
订单退款时，佣金按比例扣回。

## 提现审核

![提现审核](/screenshots/admin/affiliate-withdraws.png)

用户申请提现后出现在这里：

1. 按用户填写的渠道和账号**线下转账**；
2. 点 **打款**，状态变为已打款；
3. 或者点 **驳回** 并填写原因，佣金退回用户的可提现余额。

## 常见问题

**推广订单没有产生佣金**：检查商品是否参与推广、推广用户是否被停用、买家是否是通过推广链接进来的（30 天有效）。
