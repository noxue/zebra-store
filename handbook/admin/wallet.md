# 钱包管理与配置

## 用途

查看用户的充值记录；设置哪些支付渠道可以用来充值，以及是否只允许用余额付款。

## 入口

**用户管理 → 钱包管理**（充值记录）、**用户管理 → 钱包配置**。第一次进入前需要完成 [合规确认](./#合规确认)。

## 钱包管理（充值记录）

![充值记录](/screenshots/admin/wallet-recharges.png)

- **筛选**：充值单号、用户、支付记录 ID、渠道、提供方、状态（待支付 / 成功 / 失败 / 已过期）、创建时间、支付时间；
- **列**：充值单号、用户、支付记录、渠道、状态、金额、支付时间、创建时间。

## 钱包配置

![钱包配置](/screenshots/admin/wallet-config.png)

| 字段 | 说明 |
|---|---|
| 充值渠道 | 勾选可以用来充值的支付渠道（渠道本身的用途也要包含“钱包充值”） |
| 仅余额支付 | 打开后，买家下单**只能**用余额付款，结算页不显示在线支付渠道。适合“先充值后消费”的店 |

## 手动调整余额

在 **用户详情 → 钱包 → 调整余额** 操作，见 [用户与登录日志](./users#用户详情)。

## 常见问题

**充值成功了余额没加**：看充值记录的状态。如果是“待支付”，说明支付平台的通知没到，去 **支付记录** 查看。
