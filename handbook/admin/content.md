# 文章、Banner、素材

## 入口

- **文章管理 → 文章列表 / 文章分类**
- **内容管理 → Banner管理 / 素材管理 / 公告列表**

## 文章与公告

文章分两种类型：**博客**（`/blog`）和 **公告**（`/notice`）。两者在同一个编辑器里编辑。

![文章编辑](/screenshots/admin/posts.png)

| 字段 | 说明 |
|---|---|
| 标题、摘要、正文 | 三语；正文是富文本（可以插图、表格、链接） |
| 别名 | 网址 `/blog/别名` |
| 封面 | |
| 分类 | 仅博客 |
| 关联商品 | 仅博客，显示在文章底部 |
| 发布 | 不勾选时是草稿，前台不可见 |

**文章分类**：树形结构，名称三语、别名、上级、图标、排序、启用。

## Banner

首页顶部的轮播图。

| 字段 | 说明 |
|---|---|
| 名称 | 后台识别用 |
| 位置 | 目前只有首页顶部 |
| 标题 / 副标题 | 三语，显示在图片上 |
| 图片 / 手机图片 | 手机上优先显示手机图片 |
| 链接类型 | 无 / 站内链接 / 外部链接，以及链接地址、是否新窗口打开 |
| 开始 / 结束时间 | 只在时间范围内显示 |
| 排序、启用 | |

![Banner 管理](/screenshots/admin/banners.png)

## 素材管理

所有上传过的图片，按场景分类（商品、Banner、分类、文章、编辑器、通用等）。

- 上传：支持 jpg、png、gif、webp，默认单个不超过 10 MB；
- 点名字可以改名；可以单个删除或批量删除；
- 在商品、Banner 等页面选图时，打开的就是这个素材库。

![素材库](/screenshots/admin/media.png)

::: warning 删除素材
删除后，正在使用这张图的商品或文章会显示不出图片。
:::
