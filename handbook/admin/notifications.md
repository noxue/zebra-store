# 通知中心与邮件

## 用途

有新订单、有待人工发货的订单、充值成功、系统异常时，自动通知你（站长），而不是等你刷后台。
支持 **邮件**、**Telegram**、**飞书** 三种渠道。

> 给**买家**发的订单邮件在 [站点设置 → 订单邮件模板](./settings#订单邮件模板) 里配置，这里是给**管理员**的通知。

## 入口

**系统设置 → 通知中心**。

![通知中心](/screenshots/admin/notifications.png)

## 字段说明

**渠道**

| 渠道 | 需要填写 |
|---|---|
| 邮件 | 开关、收件人（多个）。使用站点设置里的 SMTP |
| Telegram | 开关、接收人（Telegram 用户或群组的 chat id）。使用 Telegram 设置里的 Bot Token |
| 飞书 | 开关、App ID、App Secret、接收人类型（chat_id / open_id / user_id / union_id / email）、接收人 |

**场景**：钱包充值成功、订单支付成功、有待人工发货的订单、异常告警（例如库存不足、支付异常），逐个开关。

**模板**：每个场景、每种语言的标题和正文，可以使用变量。

**其他**：默认语言；去重时间（同一事件在这段时间内只通知一次）；库存告警间隔；支付异常检查间隔；
不需要告警的商品（例如无限库存的商品）。

## 测试发送与日志

填好后点 **测试发送**：选择渠道、场景和接收人。收到消息说明配置正确。

下方的 **发送日志** 可以按渠道、状态、事件类型、是否测试、时间筛选，失败的记录会显示错误原因。

## 常见问题

**Telegram 收不到**：先在 Telegram 里给你的 Bot 发一条消息（Bot 不能主动联系没聊过天的用户）；群组要先把 Bot 拉进群。

**邮件进了垃圾箱**：给发件域名配置 SPF / DKIM，或者使用信誉好的邮件服务。
