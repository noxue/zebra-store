# 仪表盘

## 用途

一眼看清店铺的经营情况：卖了多少、赚了多少、哪些商品快卖完了、支付是否正常。

## 入口

登录后的首页，左侧菜单最上面的 **仪表盘**。

![仪表盘](/screenshots/admin/dashboard.png)

## 字段说明

**时间范围**：今日 / 7 天 / 30 天 / 自定义。数据有短暂缓存，点 **立即刷新** 获取最新数据。

**指标卡**

| 指标 | 意思 |
|---|---|
| 订单总数（已支付） | 时间范围内创建的订单数，括号里是已支付的 |
| 支付成交额（支付成功率） | 已支付订单金额，以及支付成功的比例 |
| 总成本（支付手续费） | 按商品成本价计算的成本；支付渠道手续费 |
| 总利润、利润率 | 成交额 − 成本 − 手续费 |
| 待处理订单 | 已支付但还没交付的订单（例如人工发货） |
| 新用户、在售商品 | |
| 用户余额总额 | 所有用户钱包余额之和，也就是你“欠”用户的钱 |
| 低库存商品 | 库存低于告警阈值的商品和 SKU |
| 可用卡密 | 自动发货商品还有多少张卡密 |
| 支付成功 / 失败 | 支付记录数 |

**趋势图**：每天的订单数（总数 / 已支付）、支付成功 / 失败数。

**转化漏斗**：创建订单 → 发起支付 → 支付成功 → 订单已支付 → 订单完成，以及支付转化率和完成率。

**排行**：热销商品（订单数、数量、金额、利润）、支付渠道（成功数、失败数、金额、成功率）。

**告警**：低库存、售罄、待支付订单过多、支付失败过多。点击告警跳到对应商品。

告警阈值和排行显示数量在 **系统设置 → 站点设置 → 仪表盘** 里调整；
“退款是否冲减成本”也在那里设置。

## 常见问题

**数字和订单列表对不上**：仪表盘按所选时区和时间范围统计，并有短暂缓存，点“立即刷新”再看。

**顶栏“系统更新”提示不支持一键升级**：这是正常的，升级方法见 [备份与升级](/deploy/backup-upgrade)。
