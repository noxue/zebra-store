# 后台总览与首次登录

## 登录

后台地址是 `https://你的域名/admin/`。第一次登录使用配置文件 `bootstrap` 段设置的用户名（默认 `admin`）和密码。

![后台登录页](/screenshots/admin/login.png)

- 开启了两步验证的管理员，输入密码后还要输入 6 位动态码（或者恢复码）；
- 后台开启了登录验证码时，需要先通过验证码；
- 连续输错会被暂时锁定。

## 界面

![后台仪表盘](/screenshots/admin/dashboard.png)

- **左侧菜单**：按分组排列，只显示你有权限的页面。顶部有搜索框，可以按名字快速找到菜单；屏幕较窄时自动收起，手机上变成抽屉；
- **顶栏**：语言切换（简体 / 繁體 / English）、系统版本、亮 / 暗主题、打开前台首页、退出登录。

菜单分组：

| 分组 | 包含 |
|---|---|
| 仪表盘 | 经营数据总览 |
| 商品管理 | 商品分类、商品列表、卡密库存、卡密导入、卡密导出 |
| 订单管理 | 订单列表、订单风控、退款记录 |
| 支付管理 | 支付渠道、支付记录、回调路由 |
| 用户管理 | 用户列表、钱包管理、钱包配置、登录日志、会员等级 |
| 文章管理 / 内容管理 | 文章列表、文章分类、Banner、素材、公告 |
| 营销管理 | 优惠券、活动价、批发价、礼品卡 |
| 推广返利 | 返利设置、返利用户、佣金记录、提现审核 |
| 分销商管理 | 分销概览、审核、域名、站点配置、商品配置、流水、余额、提现 |
| 对接管理 | 连接管理、商品映射、采购单管理、对账中心、API 凭证 |
| Telegram Bot | 概览、设置、帮助中心、菜单、连接状态、Bot 客户端、消息群发 |
| 系统设置 | 站点设置、通知中心、权限管理、权限审计、安全设置 |

## 合规确认

第一次打开**支付、钱包、推广财务、分销财务、对账**等和资金有关的页面时，超级管理员会看到一个确认对话框，
需要**手动输入**几段确认语（不能粘贴），声明你会在当地法律允许的范围内使用这些功能。
确认一次后永久生效。

在超级管理员确认之前，其他管理员打开这些页面会看到“需要超级管理员完成确认”的提示。

![合规确认对话框](/screenshots/admin/compliance.png)

## 新站上线清单

1. [站点设置](./settings)：站点名、站点地址、货币、注册开关；
2. [品牌与主题外观](./theme)：Logo、Favicon、主题色；
3. [安全设置](./security)：修改密码、开启两步验证；
4. [分类与商品](./products) → [卡密导入](./card-secrets)；
5. [支付渠道](./payments)；
6. 用一个普通账号在前台完整买一次，确认能收到卡密；
7. 需要多人管理时，到 [权限管理](./rbac) 添加管理员并分配角色。
