# 分类与商品

## 用途

管理店里卖什么：分类树、商品、规格（SKU）、价格、库存方式、发货方式、下单表单。

## 入口

**商品管理 → 商品分类**、**商品管理 → 商品列表**。

## 商品分类

![商品分类](/screenshots/admin/categories.png)

| 字段 | 说明 |
|---|---|
| 名称 | 三种语言 |
| 别名（slug） | 出现在网址里，例如 `game-cards` → `/categories/game-cards`。只用小写字母、数字和横线 |
| 上级分类 | 0 表示顶级分类。已经有子分类的分类不能再改层级 |
| 图标 | 从素材库选择 |
| 排序 | 数字越小越靠前 |
| 状态 | 列表里点击切换启用 / 停用。停用后前台隐藏该分类和其中的商品 |

## 商品列表

![商品列表](/screenshots/admin/products.png)

- **筛选**：关键字、库存状态（低库存 / 正常 / 无限）、分类、上下架、是否有批发价；
- **行内编辑**：直接在列表里改分类、排序；点状态切换上架 / 下架；
- **批量操作**：勾选多个商品后批量上架、下架、移动分类、删除。

## 新建 / 编辑商品

点 **新建商品** 或某一行的 **编辑**：

![商品编辑弹窗](/screenshots/admin/product-edit.png)

**基本信息**

| 字段 | 说明 |
|---|---|
| 标题 | 三种语言，至少填中文 |
| 别名（slug） | 商品网址 `/products/别名` |
| SEO 关键字 / 描述 | 三语 |
| 分类 | |
| 图片 | 可以多张，第一张是封面 |
| 简介 / 详情 / 使用说明 | 简介是纯文本；详情是富文本，显示在详情页；**使用说明**在买家收到货后显示在订单里，适合写“怎么兑换” |
| 标签 | 显示在商品卡片上 |
| 排序、是否上架 | |

**购买规则**

| 字段 | 说明 |
|---|---|
| 购买类型 | **游客可买** 或 **仅会员** |
| 最少 / 最多购买数量 | 每单的数量限制，0 表示不限 |
| 库存展示方式 | 精确数量 / 只显示充足或紧张 / 显示区间 / 隐藏 |
| 可用支付渠道 | 不选表示所有渠道都可用；选了之后结算时只显示这些渠道 |
| 参与推广返利 | 关闭后这个商品不产生推广佣金 |

**发货方式**

- **自动发货**：库存就是卡密数量，付款后自动发一张卡密。卡密在 [卡密导入](./card-secrets) 里添加；
- **人工发货**：库存是手动填的数字（`-1` 表示无限）。付款后由你在订单里填写交付内容。

**下单表单**（人工发货常用）：点 **添加字段**，每个字段设置：

| 字段 | 说明 |
|---|---|
| key | 英文标识，例如 `account` |
| 类型 | 单行文本、多行文本、手机号、邮箱、数字、下拉、单选、多选 |
| 必填 | |
| 标签 / 占位提示 | 三语 |
| 校验 | 正则、最大长度、数字最小 / 最大值、选项（下拉 / 单选 / 多选，每行一个） |

**规格（SKU）**是商品的可购买版本，例如“月卡”和“年卡”。`DEFAULT` 是只有一种版本时使用的默认规格，保持启用即可；商品至少需要一个启用的 SKU。每个 SKU 有自己的编码、名称、售价、成本价、排序和启用状态。统一代理价可留空继承该 SKU 的售价，但有效代理价不得低于成本价。各分站需要不同代理价时，在 **分销商品配置** 中按分站、商品或 SKU 设置覆盖价；分站售价可以低于主站售价，但不能低于其代理价。

商品详情与使用说明默认供主站和所有分站共用。分站需要不同内容时，在 **分销商品配置** 的商品级规则中分别开启覆盖；未开启的字段继续继承这里的主站内容。

- **自动发货**：SKU 库存等于该 SKU 的可用卡密数量。在 **商品管理 → 卡密导入** 中选中商品和 SKU，每导入一条有效卡密，就增加一份可售库存。买家下单后卡密先被预占；取消或超时释放，成功交付后变为已售出。“人工剩余库存”不控制自动发货库存。
- **人工发货**：有多个 SKU 时，在每个 SKU 的“剩余库存”中修改；商品库存由启用中的 SKU 汇总。只有默认规格且没有单独配置 SKU 时，可以直接修改商品的“人工剩余库存”。`-1` 表示不限库存。

::: tip 成本价有什么用
仪表盘用成本价计算利润；分销商的加价也不能低于成本价。
:::

## 从上游导入的商品

通过 [对接管理](./integration) 导入的商品会标记为“对接商品”，发货方式固定为上游，部分字段被锁定不能修改，
价格可以改（或由连接的加价规则自动计算）。

## 常见问题

**删除商品提示失败**：商品还有卡密、订单或者被其他数据引用。一般建议**下架**而不是删除，历史订单需要保留商品信息。

**自动发货的规格不能停用**：该规格下还有可用卡密，先导出或删除卡密。

**前台看不到商品**：检查商品是否上架、所在分类是否启用、是否有库存。

## 上游商品优先销售已采购的本地卡密

已经从上游导入的商品，也可以在「卡密库存 / 卡密导入」中选择商品和对应 SKU，录入你提前采购的卡密。商品仍保留上游映射，无需改成自动发货商品；没有卡密转换器也可使用此功能。

系统优先发本地卡密，只对不足数量向上游采购。例如买家购买 3 张、本地有 2 张时，会拆为本地发货 2 张和上游采购 1 张。价格、批发档位和优惠按原来的 3 张计算，不因拆分重新定价。本地发货和上游发货在同一个父订单下分别跟踪；取消或超时会释放尚未交付的本地预留卡密。

请核对 SKU 与卡密用途；已可直接交付的系统卡选择「直接交付」（默认）；需要转码的原始卡选择「先转换后交付」，并配置对应转换器与批次来源。
