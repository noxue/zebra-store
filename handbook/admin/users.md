# 用户与登录日志

## 用途

查找和管理买家账号：修改资料、禁用、调整余额、调整会员等级、重置两步验证。

## 入口

**用户管理 → 用户列表**、**用户管理 → 登录日志**。

## 用户列表

![用户列表](/screenshots/admin/users.png)

- **筛选**：用户 ID、关键字（邮箱 / 昵称）、状态、注册时间、最后登录时间；
- **排序**：注册时间、最后登录时间、钱包余额；
- **批量**：勾选后批量启用 / 禁用；
- **编辑**：邮箱、昵称、密码（留空表示不改）、状态、语言、邮箱是否已验证、管理员备注。

禁用用户后，该用户**立即**被退出登录，不能再登录，他作为下游的 API 凭证也会被拒绝。

## 用户详情

点用户 ID 或 **详情** 进入：

![用户详情](/screenshots/admin/user-detail.png)

| 区域 | 功能 |
|---|---|
| 资料 | 已绑定的 Telegram / Google，可以解绑；**重置两步验证**；手动设置**会员等级** |
| 钱包 | 当前余额；**调整余额**：选择增加或减少、金额、备注。减少时不能超过余额。每次调整都会留下流水 |
| 订单记录 | 这个用户的订单 |
| 支付记录 | |
| 优惠券记录 | 用过哪些券、优惠了多少 |
| 钱包明细 | 所有余额变动 |

::: tip 测试时给自己加余额
想测试下单流程又没有真实支付渠道时，给测试账号 **调整余额 → 增加**，然后在前台用余额支付。
:::

## 登录日志

买家的每一次登录尝试：用户、成功 / 失败、失败原因（密码错误、验证码错误、账号被禁用、邮箱未验证等）、IP、来源、时间。
可以按用户、邮箱、IP、状态、失败原因、时间筛选。
