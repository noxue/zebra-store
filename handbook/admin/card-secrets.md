# 卡密库存、导入、导出

## 用途

给**自动发货**商品准备“货”：每张卡密就是一段要发给买家的文本（兑换码、账号密码等），一行一张。
买家付款后系统自动取出一张放进订单。

## 入口

**商品管理 → 卡密库存 / 卡密导入 / 卡密导出**。三个页面都要先选择**商品**，有多个规格时再选择**规格**。
只有发货方式为“自动发货”的商品才会出现在选择框里。

## 卡密导入

![卡密导入](/screenshots/admin/card-secret-import.png)

**方式一：粘贴**

1. 在文本框里粘贴卡密，**一行一张**；
2. 批次号（可选，方便以后按批次查找、导出）、备注；
3. 勾选 **去重**：自动跳过本次重复的和库里已有的卡密；
4. 点 **导入**，页面显示成功导入的数量。

**方式二：上传文件**：支持 `.txt`（一行一张）和 `.csv`，其他选项同上。

## 卡密库存

![卡密库存](/screenshots/admin/card-secrets.png)

- 顶部统计：**可用**、**已预占**（有人下单还没付款）、**已售出**、总数；
- **批次面板**：每个批次的来源、备注和数量，点击批次只看这一批；
- **列表**：按状态、卡密内容、批次筛选；
- **批量操作**：可以针对“勾选的卡密”或“当前筛选结果”批量修改状态、删除、导出（txt / csv）；
- **编辑**：修改单张卡密的内容和状态。

## 卡密导出

把**可用**的卡密导出成文件，例如转移到别的店：

1. 选择商品、规格，可选批次；
2. 导出数量、格式（txt / csv）；
3. 勾选 **导出后删除**：导出的卡密从库存中移除，不会再被卖出；
4. 确认后可以复制内容或下载文件。

## 安全与并发

- 同一张卡密**不会**同时卖给两个人：库存只剩 1 张时两个人同时付款，只有一个人能拿到；
- 买家下单未付款时，卡密处于“已预占”状态；订单超时或取消后自动释放回“可用”。

## 常见问题

**导入后前台还显示售罄**：检查导入到的规格是否正确、商品是否上架。

**导入数量比粘贴的行数少**：开启了去重，重复的行被跳过了；空行也会被忽略。
