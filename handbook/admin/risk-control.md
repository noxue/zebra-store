# 订单风控

## 用途

防止有人恶意下单占库存（大量下单不付款），或者用脚本刷单。

## 入口

**订单管理 → 订单风控**。

![订单风控](/screenshots/admin/risk-control.png)

## 字段说明

| 字段 | 说明 |
|---|---|
| 启用 | 总开关 |
| IP 黑名单 | 一行一个 IP，这些 IP 不能下单 |

**游客规则**

| 字段 | 说明 |
|---|---|
| 启用 | |
| 每个 IP 最多几个待支付订单 | 超过后要先付款或等旧订单过期 |
| 每个 IP 同一商品最多占用多少数量 | 防止一个人把库存锁光 |
| 每单每个商品最多买多少 | |
| 游客订单支付超时（分钟） | 游客订单可以比会员更快过期 |
| 限流 | 开关、统计窗口（秒）、窗口内最多请求数、超过后封禁多久（秒） |

**会员规则**：每个用户最多几个待支付订单、每个 IP 最多几个待支付订单、每单每个商品最多买多少、限流。

**应用推荐游客策略**：一键填入一套适合大多数小店的游客限制。

## 常见问题

**正常买家被拦**：放宽“待支付订单数”，或者缩短支付超时时间让旧订单更快释放。

**风控记录的 IP 全是同一个**：反向代理没有正确传递真实 IP，见部署页面里的“让后端拿到买家的真实 IP”。
