# 支付渠道与支付记录

## 用途

配置买家可以用哪些方式付款，查看每一笔支付的状态，以及修改支付回调地址。

## 入口

**支付管理 → 支付渠道 / 支付记录 / 回调路由**。第一次进入前需要完成 [合规确认](./#合规确认)。

## 支付渠道

![支付渠道列表](/screenshots/admin/payment-channels.png)

顶部 **手续费设置**：是否让买家承担手续费（开启后结算页显示手续费，应付金额包含手续费）。

点 **新建渠道**：

![新建支付渠道](/screenshots/admin/payment-channel-edit.png)

**通用字段**

| 字段 | 说明 |
|---|---|
| 名称、图标 | 显示在结算页 |
| 支付提供方 | 汇付、易支付（epay）、官方（支付宝 / 微信 / PayPal / Stripe）、BEpusdt、epusdt、OKPay、TokenPay、DujiaoPay |
| 渠道类型 | 例如 alipay、wechat、usdt-trc20，可选项取决于提供方 |
| 交互方式 | 二维码 / 跳转 / 手机网页（wap）/ 电脑网页（page），可选项取决于提供方 |
| 费率、固定手续费 | 例如 0.6% + 0 |
| 最小 / 最大金额 | 订单金额不在范围内时，该渠道不可用；可以选择“超出范围时隐藏” |
| 用途 | 用于订单、用于钱包充值，可以都选 |
| 可用身份 | 游客、会员 |
| 可用会员等级 | 不选表示所有等级 |
| 启用、排序 | |
| 高级配置 | 直接编辑 JSON，一般不需要 |

**提供方配置**：每种支付平台要填的商户号、密钥等各不相同，逐个说明见 [支付渠道配置](/payment/)。

微信支付渠道有 **测试公钥** 按钮，用来检查平台公钥配置是否正确。

汇付渠道有 **交易账单** 按钮，可查询并下载支付宝、微信收款的 `TRADE_BILL`。文件生成日期通常填写交易日期的次日，完整说明见[汇付支付](/payment/huifu#下载交易对账单)。

## 支付记录

![支付记录](/screenshots/admin/payments.png)

每次买家点“去支付”都会产生一条支付记录。

- **筛选**：状态（已创建 / 待支付 / 成功 / 失败 / 已过期）、用户、订单、渠道、提供方、渠道类型、时间；
- **详情**：支付平台的交易号、支付链接、二维码内容、平台发来的原始通知、手续费策略，以及是否被新的支付取代；
- **导出**：按当前筛选导出。

## 回调路由

支付平台付款成功后，会访问本站的**回调地址**通知结果。默认地址：

| 用途 | 默认路径 |
|---|---|
| 通用支付回调（汇付、易支付、支付宝、微信、OKPay、TokenPay、epusdt、BEpusdt） | `/api/v1/payments/callback` |
| DujiaoPay | `/api/v1/payments/webhook/dujiaopay` |
| PayPal | `/api/v1/payments/webhook/paypal` |
| Stripe | `/api/v1/payments/webhook/stripe` |
| 上游对接回调 | `/api/v1/upstream/callback` |

如果你不希望回调地址被猜到，可以在这里改成自定义路径。规则：必须以 `/api/` 开头，不能和系统已有接口冲突，不能重复。
改完后记得到各支付平台同步修改通知地址。

## 常见问题

**结算页看不到某个渠道**：检查渠道是否启用、用途是否包含“订单”、可用身份和会员等级、金额范围、商品是否限定了支付渠道。

**编辑渠道时密钥显示为星号**：这是正常的掩码显示。不修改密钥字段就保存，原来的密钥会保留。
