# 品牌与主题外观

## 用途

把商店变成“你的”店：站点名、Logo、网页图标，以及二次元主题的颜色、背景、看板娘和动效。
所有外观都在后台配置，**不需要改代码**。

## 入口

- 站点名、Logo、Favicon：**系统设置 → 站点设置 → 基础配置**；
- 主题色、背景图、看板娘、动效：**系统设置 → 站点设置 → 模板配置 → 主题外观**。

![主题外观设置](/screenshots/admin/settings-theme.png)

## 字段说明

**品牌**

| 字段 | 说明 | 建议 |
|---|---|---|
| 站点名称 | 导航栏文字和网页标题 | 简短好记 |
| Logo | 导航栏左侧的图片，从素材库选择或上传 | 透明底 PNG / SVG，高度 64px 以上 |
| 站点图标（Favicon） | 浏览器标签页上的小图标 | 正方形，至少 64×64 |

**主题外观**

| 字段 | 说明 |
|---|---|
| 主色 | 主按钮、选中状态、价格高亮等。默认樱花粉 `#ff5fa2` |
| 次色 | 渐变的中间色。默认梦幻紫 `#8b5cf6` |
| 强调色 | 链接、提示信息。默认天空蓝 `#38bdf8` |
| 背景图 | 首页顶部背景，不设置时使用内置渐变 |
| 看板娘图片 | 首页和登录页右侧的角色立绘；不设置时使用内置的原创角色 |
| 登录页背景 | 前台和后台登录页的背景 |
| 樱花飘落 / 星光点缀 | 两个动效开关 |
| 默认外观 | 跟随系统 / 亮色 / 暗色。访客自己切换后以访客的选择为准 |

右侧有实时预览。**恢复默认色** 按钮把三个颜色恢复成默认值。

::: warning 注意版权
看板娘和背景图请使用你有权使用的图片，不要直接使用动漫作品里的角色。
:::

## 分站的外观

分销商可以设置自己分站的站点名、Logo、Favicon、公告和 SEO，但**主题颜色跟随主站**。

## 常见问题

**颜色改了但按钮文字看不清**：主色太浅时白色文字对比度不足，建议选饱和度较高的颜色。

**Logo 显示变形**：Logo 按高度等比缩放，请上传留白较少的横版图片。
