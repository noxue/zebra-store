# 站点设置

## 用途

店铺的所有“运营设置”：站点信息、模板、导航、关于我们、条款、公告、邮件、验证码、第三方登录等。
保存后**立即生效**，不需要重启服务器。

## 入口

**系统设置 → 站点设置**。页面顶部是多个页签，右上角的 **保存** 只保存当前页签。

![站点设置](/screenshots/admin/settings-basic.png)

## 页签与字段

### 基础配置

| 字段 | 说明 |
|---|---|
| 站点名称 | 显示在前台导航、网页标题、邮件里 |
| 站点地址（site_url） | 例如 `https://shop.example.com`。用于生成 sitemap、邮件里的链接、连接码里的地址。**一定要填** |
| 站点图标 / Logo | 见 [品牌与主题外观](./theme) |
| 站点描述 | 三种语言，显示在页脚 |
| 货币 | 例如 CNY、USD。前台价格后面会显示这个货币代码 |
| SEO | 网页标题、关键字、描述（三种语言） |
| 联系方式 | Telegram、WhatsApp，显示在页脚和关于页 |
| 页脚链接 | 自定义页脚链接 |
| 注册设置 | 是否开放注册、是否需要邮箱验证码、是否只允许特定邮箱域名 |
| 订单设置 | 未付款订单自动取消的分钟数（1–10080）、付款后多少天内允许退款（0–3650） |
| 前台脚本 | 插入到前台页面 `<head>` 或 `</body>` 前的代码，例如统计代码。可以逐条开关 |

### 模板配置

- **页面模式**：卡片模式（默认）或列表模式（首页按分类列出所有商品，适合商品多的店）；
- **主题外观**：主题色、背景图、看板娘等，见 [品牌与主题外观](./theme)。

### 导航配置

开关前台导航里的 **博客**、**公告**、**关于我们**，并添加自定义菜单（标题三语、内链或外链、新窗口打开、图标、排序）。

### 关于我们 / 法律条款 / 首页公告

- **关于我们**：页头标题、简介、服务列表（最多 12 项）、联系方式，全部三语；
- **法律条款**：服务条款和隐私政策（富文本，三语），注册页会链接过去；
- **首页公告**：开关、类型、标题、内容、开始和结束时间。在时间范围内，访客打开首页会看到弹窗。

### 邮件配置 (SMTP)

| 字段 | 说明 |
|---|---|
| 启用 | 关闭后不发送任何邮件 |
| 服务器、端口 | 例如 `smtp.qq.com`、465 |
| 用户名、密码 | 很多邮箱要用“授权码”而不是登录密码。密码保存后显示为掩码，不修改就不会被清空 |
| 发件地址、发件人名称 | |
| SSL / TLS | 465 端口选 SSL，587 端口选 TLS |
| 订单邮件通知 | 是否给买家发送订单状态邮件 |
| 验证码设置 | 有效期、位数、最多输错次数、重发间隔 |

填完点 **发送测试邮件** 确认能发出。

### 订单邮件模板

选择场景（例如“已支付”“已交付”“已退款”），分别编辑三种语言的标题和正文。
可用变量：订单号、状态、金额、退款金额、退款原因、货币、交付内容、站点名、站点地址。
**恢复默认** 按钮会把当前场景恢复成系统模板。

### 验证码配置

- 类型：不使用 / 图形验证码 / Cloudflare Turnstile；
- 场景：登录、注册发送验证码、找回密码发送验证码、游客下单、兑换礼品卡，逐个勾选；
- 图形验证码的长度、尺寸、干扰点；Turnstile 的 Site Key 和 Secret Key。

### Telegram 设置 / Google 登录

- **Telegram**：开关、Bot 用户名、Bot Token、OIDC Client Secret（这两个只写不读）、OIDC 回调地址、Mini App 地址、登录有效期；
- **Google**：开关、Client ID。

### 仪表盘

退款是否冲减成本；各类告警阈值（低库存数量、售罄商品数、待支付订单数、支付失败数）；排行显示条数。

### 上游同步

从上游进货时的同步参数：同步间隔（分钟）、下单前是否先向上游检查库存、同时同步几个连接、每页数量、最多页数。
见 [对接管理](./integration)。

## 常见问题

**改了站点名，前台没变**：按 Ctrl+F5 强制刷新；配置有缓存但保存时会自动清除。

**测试邮件发不出去**：多数是端口和 SSL/TLS 选错，或者密码应该填授权码。云服务器常常封了 25 端口，请用 465 或 587。
