# 分销商管理

## 用途

审核分销商、分配子域名、管理分站配置和加价规则、查看分销流水与余额、处理提现。
分站的整体玩法和利润计算见 [分站](/reseller/)。

## 入口

左侧菜单 **分销商管理**。分销概览、分销流水、分销余额、分销提现需要先完成 [合规确认](./#合规确认)。

::: info 先开启分销功能
后台能看到这些页面，但前台要能申请、分站域名要能访问，需要在配置文件里设置 `reseller.enabled: true` 等，
见 [开启分销功能](/reseller/#开启分销功能)。
:::

## 分销概览

![分销概览](/screenshots/admin/reseller-operations.png)

选择时间范围（今日 / 7 天 / 30 天 / 自定义）：分销商数量（各状态）、分站订单数、已支付订单、告警；
分销商排行（订单数、已付订单、启用的域名、是否配置了站点、最后下单时间）；
财务：成交额、利润、退款扣回、已提现，以及当前可用、锁定、负余额、待提现金额。

## 分销商审核

![分销商审核](/screenshots/admin/reseller-profiles.png)

| 操作 | 说明 |
|---|---|
| 通过 | 设置**默认加价**（分销商没有单独设置时使用）和**最高加价**（分销商加价不能超过它） |
| 驳回 | 填写原因，用户可以重新申请 |
| 禁用 / 恢复 | 禁用后分站域名**立即**无法访问，恢复后重新可用 |
| 编辑 | 修改默认 / 最高加价、结算状态（正常 / 冻结，冻结后不能提现） |
| 详情 | 见下 |

**分销商详情**：资料、**分配系统子域名**（例如填 `sakura`，分站地址就是 `sakura.你的基础域名`）、
域名列表（可以设为主域名）、商品设置摘要，以及订单、流水、提现、余额四个页签。

## 分销域名

所有分销商的域名：系统子域名和自定义域名。可以按分销商、类型、状态、验证状态筛选，**审核通过**或**停用**。

## 分销站点配置

所有分销商的分站设置。可以帮分销商**编辑**，或者**重置**为默认。字段：

站点名、Logo、Favicon、公告（开关、类型、标题和内容三语）、客服（Telegram、WhatsApp、邮箱、客服链接）、
SEO（标题、关键字、描述三语、分享图）、页脚链接、导航开关。

![分销站点配置](/screenshots/admin/reseller-site-configs.png)

## 分销商品配置

所有分销商的商品加价规则。可以按分销商、商品、是否上架、定价方式筛选。

编辑时可以按商品或者按规格设置：是否上架、定价方式（继承默认 / 按百分比加价 / 固定加价 / 固定售价）及数值。
**预览** 会显示最终售价，并指出不合法的规则（低于基础价或成本价、超过最高加价）。**重置** 删除该规则。

## 分销流水

每一笔分销资金变动：

| 类型 | 意思 |
|---|---|
| 订单利润 | 分站订单成交产生的利润 |
| 退款扣回 | 订单退款，按比例扣回利润 |
| 手动调整 | |
| 提现锁定 / 提现支付 | 分销商申请提现和你打款 |

状态：待确认（结算确认期内）、可用、锁定、已提现、已取消。

## 分销余额

每个分销商每种货币一行：可用、锁定、负余额、状态（正常 / 负余额 / 冻结审核 / 停用）。

## 分销提现

![分销提现](/screenshots/admin/reseller-withdraws.png)

分销商申请提现后出现在这里。按对方填写的渠道和账号**线下转账**后点 **打款**；或者点 **驳回** 并填写原因，
金额退回分销商的可用余额。
