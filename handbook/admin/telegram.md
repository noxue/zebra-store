# Telegram Bot

## 用途

配合 Telegram Bot 客户端，让买家在 Telegram 里浏览商品、下单、查询订单，并支持给绑定了 Telegram 的用户群发消息。

::: info 需要单独的 Bot 客户端
这些页面配置的是 Bot 的内容和对接凭证。Bot 本身是一个单独运行的客户端程序，通过 **Channel API** 与本站通信。
:::

## 入口

左侧菜单 **Telegram Bot** 分组。

![Telegram Bot 概览](/screenshots/admin/telegram-bot.png)

## 页面说明

| 页面 | 用途 |
|---|---|
| 概览 | Bot 运行状态、功能入口 |
| 基础设置 | 开关、默认语言、Bot 显示名称、介绍（三语）、客服链接、封面图；欢迎语开关和内容 |
| 帮助中心 | 帮助条目（最多 12 条）：标题、摘要、内容（三语）、是否显示客服链接，可以上下移动排序 |
| 菜单配置 | Bot 菜单按钮（最多 20 个）：名称（三语）、动作类型（内置功能 / 网址 / Web App / 命令），可以排序 |
| 连接状态 | 是否在线、最后心跳时间、版本、Webhook 状态、授权状态、配置同步时间、警告 |
| Bot 客户端 | 管理 Channel API 凭证：新建（名称、描述、Bot Token、回调地址）、复制 Key / Secret、重置 Secret、启用 / 停用、删除 |
| 消息群发 | 给所有或指定的 Telegram 绑定用户群发 HTML 消息（可带附件），查看发送进度和成功 / 失败数 |

## 常见问题

**重置 Secret 后 Bot 不工作了**：Bot 客户端需要换成新的 Secret。停用和重置都会让旧凭证立即失效。

**群发没有收件人**：只有在前台绑定了 Telegram 的用户（或通过 Telegram 登录的用户）才能收到。
