# 斑马小铺是什么

**斑马小铺（Zebra Store）** 是一个卖虚拟商品的网上商店，也就是大家常说的“发卡网”。
你把商品（比如会员兑换码、游戏点卡、软件激活码）上架，买家下单付款后，
系统会**自动把卡密发给买家**，不需要你在线守着。

斑马小铺采用 Rust 后端和 Vue 3 前端，可以直接使用 SQLite，也可以切换到 MySQL 或 PostgreSQL。
它默认不依赖 Redis，单个可执行文件即可运行；对接模块支持 Zebra Store、dujiao-next、异次元和萌次元协议。

## 它能做什么

- **卖东西**：分类、商品、多规格（SKU）、库存、自动发卡、人工发货、下单表单。
- **收钱**：易支付、支付宝、微信、PayPal、Stripe、USDT 等网关，以及站内钱包余额。
- **做营销**：优惠券、活动价、会员等级折扣、批发价、礼品卡、推广返利。
- **管理**：仪表盘报表、订单、退款、用户、风控、权限（多个管理员分工）、通知（邮件 / Telegram / 飞书）。
- **对接货源**：从别的发卡站进货（你是**下游**），或者给别人供货（你是**上游**）。详见 [对接](/integration/)。
- **开分站**：别人申请成为分销商，用子域名开自己的店，卖你的商品并加价赚差价。详见 [分站](/reseller/)。

## 适合谁

- 想开一个发卡小店、但不想折腾复杂环境的新手：一台 1 核 1G 的 VPS 就能跑。
- 已有其他发卡站、希望把商品和订单接入统一供应链的站长。
- 有多个站点、需要互相进货供货的站长。
