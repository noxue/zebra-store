# 名词解释

第一次接触发卡网时，下面这些词会反复出现。

| 名词 | 意思 |
|---|---|
| **卡密** | 卡号 + 密码，泛指一段要发给买家的文本，比如兑换码、激活码、账号密码。一行一个。 |
| **自动发货** | 商品绑定了卡密库存，买家付款后系统自动取出一张卡密放进订单。 |
| **人工发货** | 没有卡密，付款后由你在后台手动填写交付内容，比如代充。 |
| **下单表单** | 人工发货商品可以要求买家填写信息（游戏账号、区服等），在后台商品里配置。 |
| **SKU / 规格** | 同一个商品的不同版本，比如“月卡 / 季卡”，每个 SKU 有自己的价格和库存。 |
| **游客下单** | 不注册也能买：填邮箱和一个“查询密码”，之后凭这两个查订单。 |
| **钱包 / 余额** | 用户在站内的余额，可以充值、用来付款，退款也可以退到余额。 |
| **会员等级** | 按累计充值或消费自动升级，每个等级可以有折扣。 |
| **活动价** | 限时降价。 |
| **批发价** | 买得越多单价越低，比如“满 5 件每件 8 元”。 |
| **礼品卡** | 一串兑换码，兑换后给钱包加余额。 |
| **推广返利** | 用户分享推广链接，别人通过链接下单后，推广人获得佣金。 |
| **上游 / 供货方** | 卖货给你的站点。你从它那里进货，买家在你这里下单时，系统自动去上游采购。 |
| **下游 / 采购方** | 从你这里进货的站点。 |
| **对接** | 两个站点之间自动进货和供货的连接。 |
| **采购单** | 你的站点向上游下的订单，每个对接商品的订单都会生成一个。 |
| **API 凭证** | 给下游站点用的账号密钥（Key + Secret），在个人中心申请，管理员审核后生效。 |
| **连接码** | Zebra Store 协议的“一键接入码”，里面包含地址和密钥，下游粘贴后自动完成配置。 |
| **兼容密钥** | 给异次元 / 萌次元站点用的单独密钥（app_key）。 |
| **分站 / 分销商** | 有人在你的平台上开一个自己的店（子域名），卖你的商品并加价赚差价。 |
| **利润快照** | 分站订单成交那一刻记录下来的分销商利润，后续改价不会影响已成交订单。 |
| **结算确认期** | 分销利润（或推广佣金）要等几天才能提现，防止买家退款后利润已经被提走。 |
| **合规确认** | 超级管理员第一次使用支付相关功能前，必须手动输入几段确认语，确认遵守当地法律。 |
| **RBAC** | 基于角色的权限控制：给管理员分配角色，每个角色只能访问特定页面。 |
| **2FA / 两步验证** | 登录时除了密码还要输入手机验证器 App 上的 6 位动态码。 |
