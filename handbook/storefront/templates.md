# 店铺模板效果对比

站长可在 **管理后台 → 系统设置 → 模板配置** 选择店铺模板，保存后用户前台立即采用新样式。模板会改变首页、商品列表、卡片和页脚的视觉风格。

| 模板 | 视觉特点 | 适用场景 |
|---|---|---|
| 经典模板 | 粉紫配色、圆润卡片 | 轻松活泼的店铺 |
| 数字保险库 | 深靛蓝与青色 | 数字产品和科技服务 |
| 极光清新 | 青绿与柔和背景 | 简洁清爽的店铺 |
| 暖调杂志 | 米色与暖棕 | 内容型或生活方式店铺 |
| 曜金典藏 | 深色与金色 | 会员和精品商品 |

实际展示的商品、图片和站点名称取决于你的商店数据。

模板之外，还可选八组快捷配色或逐项修改主色、次色、强调色、背景色、卡片色和文字色。**恢复默认配色** 会恢复当前模板的颜色。页面区块开关可分别控制首页顶部横幅、页脚快速链接和仓库链接；这三项默认显示。访客曾手动选择亮色或暗色时，浏览器会继续使用访客的选择。
