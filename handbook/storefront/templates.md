# 店铺模板效果对比

站长可在 **管理后台 → 系统设置 → 模板配置** 选择店铺模板，保存后用户前台立即采用新样式。模板会改变首页、商品列表、卡片和页脚的视觉风格。下图使用同一批演示商品，分别以各模板的默认配色展示；截图预览没有改动线上站点配置。

| 模板 | 首页 | 商品列表 |
|---|---|---|
| 经典模板：粉紫、圆润，适合轻松活泼的店铺 | [![经典模板首页](/screenshots/templates/classic-home.png)](/screenshots/templates/classic-home.png) | [![经典模板商品列表](/screenshots/templates/classic-products.png)](/screenshots/templates/classic-products.png) |
| 数字保险库：深靛蓝与青色，适合数字产品和科技服务 | [![数字保险库首页](/screenshots/templates/vault-home.png)](/screenshots/templates/vault-home.png) | [![数字保险库商品列表](/screenshots/templates/vault-products.png)](/screenshots/templates/vault-products.png) |
| 极光清新：青绿与柔和背景，适合简洁清爽的店铺 | [![极光清新首页](/screenshots/templates/aurora-home.png)](/screenshots/templates/aurora-home.png) | [![极光清新商品列表](/screenshots/templates/aurora-products.png)](/screenshots/templates/aurora-products.png) |
| 暖调杂志：米色与暖棕，适合内容型或生活方式店铺 | [![暖调杂志首页](/screenshots/templates/atelier-home.png)](/screenshots/templates/atelier-home.png) | [![暖调杂志商品列表](/screenshots/templates/atelier-products.png)](/screenshots/templates/atelier-products.png) |
| 曜金典藏：深色与金色，适合会员和精品商品 | [![曜金典藏首页](/screenshots/templates/noir-home.png)](/screenshots/templates/noir-home.png) | [![曜金典藏商品列表](/screenshots/templates/noir-products.png)](/screenshots/templates/noir-products.png) |

点击图片可查看完整尺寸。实际展示的商品、图片和站点名称取决于你的商店数据。

模板之外，还可选八组快捷配色或逐项修改主色、次色、强调色、背景色、卡片色和文字色。**恢复默认配色** 会恢复当前模板的颜色。页面区块开关可分别控制首页顶部横幅、页脚快速链接和仓库链接；这三项默认显示。访客曾手动选择亮色或暗色时，浏览器会继续使用访客的选择。
