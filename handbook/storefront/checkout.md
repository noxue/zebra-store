# 购物车与下单

## 购物车

在商品详情点 **加入购物车**，右上角购物车图标会显示数量。打开 `/cart`：

- 修改数量（受最少 / 最多购买量和库存限制）；
- 删除商品，删除后几秒内可以撤销；
- 页面会自动刷新每个商品的最新库存；
- 右侧显示合计，点 **去结算**。

购物车保存在浏览器里，关掉网页再打开还在。

![购物车](/screenshots/storefront/cart.png)

## 立即购买

商品详情页点 **立即购买** 会跳过购物车，只结算这一个商品。

## 结算页

![结算页](/screenshots/storefront/checkout.png)

结算页从上到下：

1. **商品清单**：每件商品的实际单价（已算上各种优惠）；
2. **下单表单**：人工发货商品可能要求填写信息，比如游戏账号、区服。带星号的是必填，格式不对会提示；
3. **优惠券**：输入券码后金额会重新计算（分站上不显示优惠券）；
4. **购买身份**（未登录时）：
   - **游客购买**：邮箱和查询密码可同时留空。系统会为当前浏览器生成 UUID 身份并保存在 `localStorage`，刷新或重新打开网站后仍可直接查询订单；
   - 如需在其他设备查询，请同时填写邮箱和查询密码。网站同样会在当前浏览器保存并自动回填这两项；
   - **会员购买**：跳到登录页，登录后回来继续；
5. **金额明细**：原价、优惠券、活动优惠、批发优惠、会员优惠、应付金额；
6. **使用余额**（已登录时）：勾选后先用钱包余额抵扣。后台开启“仅余额支付”时这一项会被强制勾选；
7. **支付方式**：显示后台配置的支付渠道。买家承担手续费时，会显示费率；金额不在渠道的限额范围内时，该渠道不可选；
8. **提交订单**：成功后跳转到支付页。

::: tip 游客下单也要验证码？
后台 **系统设置 → 验证码配置** 勾选了“游客下单”场景时，提交前需要通过验证码。
:::

## 多种商品一起买

购物车里有多种商品时，系统会生成一个**父订单**和多个**子订单**（每种商品一个），
一次付款，分别发货。订单详情页里能看到每个子订单的交付内容。

## 订单会被自动取消吗

会。下单后 **15 分钟**（后台可改）内没有付款，订单自动取消，占用的库存和优惠券次数都会退回。
取消后即使支付平台晚到了付款通知，订单也不会被当作已付款；遇到这种情况请联系站长核实。

未付款的订单也可以在订单详情页点 **取消订单** 手动取消。

## 下单被拒绝的常见原因

| 提示 | 原因 |
|---|---|
| 库存不足 | 商品刚好卖完，或者上游缺货 |
| 超过购买限制 | 数量小于最少购买量或大于最多购买量 |
| 仅会员可购买 | 需要先登录 |
| 待支付订单过多 / 请求过于频繁 | 触发了后台的订单风控，先付款或取消之前的未付订单 |
| 表单校验失败 | 下单表单有必填项没填或格式不对 |
