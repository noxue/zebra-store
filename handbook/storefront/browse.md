# 浏览、搜索、语言与主题

## 首页

首页从上到下是：

- **轮播 Banner**：后台 **内容管理 → Banner管理** 配置，手机上会使用单独的手机图；
- **推荐商品**：最新上架的商品；
- **最新文章**：只在后台导航里开启了博客或公告时显示；
- **公告弹窗**：后台开启首页公告后，访客第一次打开首页会弹出。可以选择“本次关闭”“今天不再显示”或“不再显示”。

如果后台把 **模板配置 → 列表模式** 打开，首页会变成“左边分类、右边按分类分组的商品列表”，适合商品很多的店。

![首页公告弹窗](/screenshots/storefront/announcement.png)

## 商品列表与搜索

`/products` 左侧是分类树（父分类可以折叠），右侧是商品卡片。

- 点分类后地址变为 `/categories/分类别名`，方便分享；
- 顶部搜索框输入关键字会自动筛选（停止输入 0.3 秒后生效）；
- 找不到商品时会出现 **清除筛选** 按钮；
- 商品卡片上有“游客可买 / 仅会员”“自动发货 / 人工发货”、库存状态等标签，以及 **快速购买** 按钮。

## 商品详情

![商品详情页](/screenshots/storefront/product-detail.png)

| 区域 | 说明 |
|---|---|
| 图片 | 多图可切换 |
| 标签 | 购买类型（游客 / 会员）、发货方式（自动 / 人工）、库存状态 |
| 价格 | 有活动价时显示原价划线；登录后显示会员价；达到批发数量时显示批发价 |
| 规格（SKU） | 每个规格单独显示库存，售罄的规格不能选 |
| 数量 | 受“最少购买 / 最多购买”和库存限制 |
| 按钮 | **加入购物车**、**立即购买**；仅会员商品未登录时显示 **登录后购买** |
| 详情 | 富文本介绍、相关文章 |

库存怎么显示由后台商品的“库存展示方式”决定：精确数量、只显示充足/紧张、显示区间，或完全隐藏。

## 切换语言

导航栏右侧的语言按钮可以切换 **简体中文 / 繁體中文 / English**。
商品标题、分类、文章等内容如果在后台填了对应语言，会一起切换；没填的会显示中文。
选择会保存在浏览器里，下次打开保持不变。

## 亮色 / 暗色主题

导航栏的太阳 / 月亮按钮切换亮色和暗色主题，默认跟随系统设置。
樱花飘落等动效可以在后台关闭；如果系统开启了“减少动态效果”，前台会自动关掉动效。

![暗色主题](/screenshots/storefront/home-dark.png)

## 博客、公告、关于我们

- `/blog`：博客文章，可以搜索；
- `/notice`：系统公告；
- `/about`：关于我们（内容在后台 **系统设置 → 关于我们** 编辑）；
- `/terms`、`/privacy`：服务条款和隐私政策（后台 **系统设置 → 法律条款**）。

导航栏显示哪些入口，由后台 **系统设置 → 导航配置** 决定，也可以添加自定义链接。
