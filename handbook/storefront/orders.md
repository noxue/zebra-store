# 订单查询与交付

## 会员查单

个人中心 → **订单**（`/me/orders`）：

- 顶部统计各状态的订单数；
- 可以按状态筛选、按订单号搜索；
- 切换到 **充值订单** 页签查看钱包充值记录；
- 点订单进入详情，待支付订单可以直接 **去支付**。

![我的订单](/screenshots/storefront/me-orders.png)

## 游客查单

打开 `/guest/orders`（导航栏“订单查询”），输入下单时填写的**邮箱**和**查询密码**，可选填订单号。
浏览器会记住这次输入，页面上有 **清除记录** 按钮。邮箱或密码不对时查不到任何订单。

![游客查单](/screenshots/storefront/guest-orders.png)

## 订单状态

| 状态 | 意思 |
|---|---|
| 待支付 | 还没付款，超时会自动取消 |
| 已支付 | 已付款，正在处理 |
| 发货中 | 正在发货（例如正在向上游采购） |
| 部分交付 | 多件商品里有一部分已经交付 |
| 已交付 | 全部交付完成 |
| 已完成 | 交易结束 |
| 已过期 / 已取消 | 没付款或手动取消 |
| 部分退款 / 已退款 | 站长做了退款 |

## 订单详情里有什么

![订单详情与卡密](/screenshots/storefront/order-detail.png)

- **金额**：原价、各项优惠、实付、余额支付和在线支付各多少、已退款金额；
- **时间**：下单、付款、过期、取消时间；
- **商品**：每件商品的单价、规格、下单表单填写的内容；
- **交付内容**：
  - 自动发货的商品直接显示卡密，一行一张，可以 **复制** 或 **下载** 成 txt 文件。卡密很多时页面只显示一部分，请下载完整文件；
  - 人工发货的商品在站长发货后显示交付内容；
  - 商品有“使用说明”时，会显示在交付内容下面；
- **子订单**：一次买了多种商品时，每种商品一个子订单，分别显示交付内容；
- **退款记录**：退款金额、时间和备注。

## 人工发货要等多久

人工发货的商品需要站长处理，时间取决于店铺。站长发货后订单状态变为“已交付”，
如果店铺开启了邮件通知，你还会收到一封发货邮件。
