# 支付渠道配置：通用字段与回调地址

## 新建渠道的步骤

1. 先到对应的支付平台申请商户、拿到商户号和密钥（每个平台的申请方式不同，见左侧各页面）；
2. 后台 **支付管理 → 支付渠道** → **新建渠道**；
3. 填写下面的**通用字段**；
4. 选择 **支付提供方**，填写该提供方的**专属字段**；
5. 保存，启用；
6. 在支付平台后台把**通知地址**（回调地址）设为本站地址（见下表）；
7. 用小金额在前台真实付一笔，确认订单能自动变成已支付。

::: warning 合规
第一次进入支付管理时需要完成 [合规确认](/admin/#合规确认)。请只接入你在当地可以合法使用的支付方式。
:::

## 通用字段

| 字段 | 说明 |
|---|---|
| 名称、图标 | 显示在结算页，例如“支付宝” |
| 支付提供方 | 汇付、易支付、官方（支付宝 / 微信 / PayPal / Stripe）、BEpusdt、epusdt、OKPay、TokenPay、DujiaoPay |
| 渠道类型 | 例如 `alipay`、`wechat`、`usdt-trc20` |
| 交互方式 | **二维码**（页面上显示二维码）、**跳转**（跳到支付平台页面）、**手机网页**、**电脑网页** |
| 费率 / 固定手续费 | 用于计算手续费；开启“买家承担手续费”时加到应付金额上 |
| 最小 / 最大金额 | 超出范围时不可用或隐藏 |
| 用途 | 订单、钱包充值 |
| 可用身份 / 会员等级 | 限制谁能看到这个渠道 |
| 汇率 / 目标货币 | 部分提供方有：店铺用人民币标价、支付平台收美元时，填汇率换算 |
| 启用、排序 | |

## 回调地址（通知地址）

付款成功后，支付平台会访问本站的回调地址。把下面的地址填到支付平台后台，或者渠道配置的 `notify_url` 字段：

| 提供方 | 回调地址 |
|---|---|
| 汇付、易支付、支付宝官方、微信官方、OKPay、TokenPay、epusdt、BEpusdt | `https://你的域名/api/v1/payments/callback` |
| PayPal | `https://你的域名/api/v1/payments/webhook/paypal?channel_id=渠道ID` |
| Stripe | `https://你的域名/api/v1/payments/webhook/stripe?channel_id=渠道ID` |
| DujiaoPay | `https://你的域名/api/v1/payments/webhook/dujiaopay?channel_id=渠道ID` |

“渠道ID”是支付渠道列表里的 ID 列。这些路径可以在 **支付管理 → 回调路由** 改成自定义路径，改了之后支付平台那边也要同步修改。

::: tip 回调地址必须能从公网访问
支付平台在外网，访问不到内网地址，本地测试时回调不会到达。回调地址请用 HTTPS。
:::

## 支付平台和本站的“返回地址”

`return_url` / `success_url` 是买家付完款后浏览器跳回的地址，一般填 `https://你的域名/pay`。
买家回到支付页后，页面会自动查询结果并跳到订单详情。

## 测试

- 用最小金额在前台买一次，或者给钱包充值一次；
- 在 **支付管理 → 支付记录** 打开这条记录，能看到支付平台发来的原始通知；
- 订单没有变成已支付时，看 [排错指南](/faq/troubleshooting#买家付款后订单没有变成已支付)。
