### 让后端拿到买家的真实 IP

风控、限流和登录日志都需要买家的真实 IP。反向代理通过 `X-Forwarded-For` 头把 IP 传给后端，
但后端**只相信** `server.trusted_proxies` 里列出的代理。默认值是 `127.0.0.1/32` 和 `::1/128`，
反向代理和后端在同一台机器上时**不用改**。

反向代理在别的机器或者 Docker 容器里时，把它的 IP 或网段加进去，例如：

```yaml
server:
  trusted_proxies: ["127.0.0.1/32", "::1/128", "172.28.0.0/24"]
```

`0.0.0.0/0` 这种“相信所有人”的写法会被拒绝，因为那样任何人都能伪造 IP。
