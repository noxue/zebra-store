# 选择部署方式

这一部分只讲一件事：**把一个斑马小铺站点（后端 + 用户前台 + 管理后台）部署到服务器上，并通过 HTTPS 访问**。
四种方式任选一种，每一页都从一台空服务器讲到网站能打开：

| 方式 | 适合谁 | 你需要会什么 |
|---|---|---|
| [宝塔面板](./bt-panel) | 习惯用网页面板管理服务器的新手 | 会点鼠标、会上传文件 |
| [Docker Compose](./docker) | 服务器上已经在用 Docker | 会复制粘贴命令 |
| [Nginx](./nginx) | 服务器上已经有 Nginx，或者习惯 Nginx | 会编辑配置文件 |
| [Caddy](./caddy) | 新服务器，想要最少的配置、自动 HTTPS | 会编辑配置文件 |

::: tip 不知道选哪个？
- 服务器装了宝塔 → 选 **宝塔面板**；
- 一台全新的服务器 → 选 **Caddy**（证书全自动，配置文件最短）；
- 已经有 Nginx 在跑别的网站 → 选 **Nginx**；
- 所有服务都用 Docker 管理 → 选 **Docker Compose**。
:::

只想在自己电脑上试一试或者改代码？看 [本地开发运行](./local-dev)。

## 所有方式都一样的地方

- 后端是一个叫 `zebra-store` 的程序，默认监听 **8081** 端口，第一次启动时自动建表、创建管理员；
- 前台和后台是两个静态网页文件夹，由 Web 服务器直接提供；
- Web 服务器把 `/api/`、`/uploads/` 等路径转发给后端；
- 默认用 **SQLite** 数据库（一个文件，不用另外安装），想换 MySQL / PostgreSQL 看 [切换数据库](./database)；
- **不需要 Redis**。

部署之后还会用到：[配置文件详解](./config)、[环境变量覆盖](./env)、[备份与升级](./backup-upgrade)。

## 部署完成后要做的第一件事

1. 用配置文件里设置的管理员账号登录后台（`https://你的域名/admin/`）；
2. 第一次进入支付或钱包相关页面时，按提示完成**合规确认**（见 [后台总览](/admin/#合规确认)）；
3. 到 **系统设置 → 站点设置** 修改站点名、上传 Logo、填写站点地址 `site_url`（见 [站点设置](/admin/settings)）；
4. 到 **安全设置** 给管理员开启两步验证（见 [安全设置](/admin/security)）；
5. 建分类和商品、导入卡密、配置支付渠道，就可以开张了。
